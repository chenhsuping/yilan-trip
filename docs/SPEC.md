## 1. 產品概述

將一份宜蘭 2 天 1 夜的親子行程，從單張圖片升級為「會動、可互動、隨時間更新」的網頁。
目標使用者為參加此趟旅行的家庭成員（10 位大人、5 位兒童），用途為：行前瀏覽、行中導航、費用分攤查詢、以及分享給群組。

**設計語彙**：宜蘭在地元素（溫泉、三星蔥、雞）＋親子可愛風；暖色系配色、圓角、漸層、輕動畫。

## 4. 功能規格

### 4.1 分頁切換（Tabs）
- 四個分頁：**DAY 1** / **DAY 2** / **住房指南**（見 4.10）/ **入住須知**（見 4.11）。
- 切換時觸發煙火動畫（DAY 1 暖色、DAY 2 冷色、住房指南紫色、入住須知金綠色，由 `TAB_HUE` 定義）。
- 分頁列 sticky 固定於頂端。
- 後兩個分頁不是行程日，切過去時自動隱藏「💰 費用試算」「回程結語」與「📍 目前行程」浮動鈕（`INFO_TABS` 陣列判定）。

### 4.2 時間軸（Timeline）
- 垂直時間軸，左側為序號圓點（依類型配色），右側為行程卡片。
- 卡片捲動進入視窗時淡入（IntersectionObserver，門檻 0.15）。

### 4.3 地圖導航
- 每個地點的地址為連結，點擊於新分頁開啟 Google Maps 搜尋。
- 連結格式：`https://www.google.com/maps/search/?api=1&query=<地點名稱+地址>`（URL 編碼）。

### 4.4 費用試算（Calculator）
含「大人 / 兒童」人數 stepper（預設 **大人 10、兒童 5**），即時計算：

| 項目 | 公式 | 是否隨人數變動 |
|------|------|----------------|
| 白色城堡包棟 | 固定 43,200 | 否 |
| 代烤燒肉 | 固定 17,000 | 否 |
| 免睡殿 | （大人＋兒童）× 150 | 是 |
| 萌萌森林 | 大人 × 250 ＋ 兒童 × 150 | 是 |
| **總計（不含餐飲）** | 上列四項加總 | — |

- **均分規則**：總額（含兒童門票）**只由大人均分**，兒童不分攤。
  `每位大人 = ceil(總額 ÷ 大人數)`（無條件進位，確保收足）。
- 餐飲（桶仔雞、莫內咖啡）與伴手禮（奕順軒）不列入試算，依現場為準。
- 免睡殿 6 歲以下、75 歲以上免費，如有免費者請自行下調兒童人數。
- 數字更新時有 count-up 與縮放動畫。

**範例（10 大 5 小）**：總計 NT$65,700，每位大人 NT$6,570。

### 4.5 依現在時間定位行程
- 以訪客**裝置本地時間**判斷目前進度。
- 行程時間表（供程式判斷，`[時,分]`）：
  - DAY 1（2026-08-29）：11:30 / 13:30 / 15:00 / 18:00
  - DAY 2（2026-08-30）：11:00 / 11:30 / 12:30 / 14:20
- 三種狀態：
  - **出發前**：標記第一站，徽章顯示「還有 N 天出發」；出發當天但還沒到第一站時間則顯示「今天出發」。
    天數以**日曆日**（兩邊午夜時間點）相減，不是拿時間差直接除以 24 小時 —— 早期版本用 `Math.ceil((first.t-now)/DAY_MS)`，出發當天只要還沒到第一站時間（哪怕只差 5 分鐘）都會被無條件進位成「還有 1 天」，跟行程根本沒有隔一天矛盾。
  - **旅程中**：切到當天、捲動至當下站、卡片高亮＋「🔴 進行中」徽章。（此狀態才會自動捲動）
  - **結束後**（末站起 +3 小時）：標記末站「✅ 行程結束」。
- 右下「📍 目前行程」浮動按鈕：任何時候點擊都跳到當下該站。
- 每 60 秒自動更新徽章位置（不強制切頁／捲動，避免干擾閱讀）。

### 4.6 動畫清單
Hero 標題流光漸層、太陽脈動、雲朵飄移、emoji 浮動、溫泉蒸氣、載入煙火、時間軸圓點光環、卡片淡入＋hover 上浮與流光掃過、金額 count-up、進行中徽章閃爍、背景光點（canvas bokeh）。
蓋版視窗另有遮罩淡入與卡片彈入（見 4.9、4.10）；天氣預報鈕的 emoji 輕晃、逐時表切換時淡入。
**全部動畫遵守 `prefers-reduced-motion`，使用者關閉動態時停用。**

- 以 CSS 變數（token）定義配色，`prefers-color-scheme` 自動切換；亦支援 `data-theme` 覆蓋。
- 兩種主題皆經設計，非單純反色。

### 4.9 出遊兩天天氣預報（蓋版視窗）

行前與行中掌握天氣用。**1.3 版起本視窗只做天氣**：原本的 NCDR 各國颱風路徑動畫（1.1／1.2 版的 4.9）已整段移除，相關常數、影片與靜態圖降級邏輯一併刪除。

**觸發方式**
- 右下浮動鈕 **🌤️ 天氣預報**（位於「📍 目前行程」上方），常駐可點。
- **自動開啟有期限**：只在 `Date.now() < WX_AUTO_END` 時延遲 900ms 自動彈出一次；`WX_AUTO_END` = 出發當天（`dayDates[0]`）**台灣時間 09:30**，程式碼寫成 `Date.UTC(Y, M, D, 1, 30, 0)`（台灣 09:30 = UTC 01:30）。過了這個時間點就只能手動開 —— 行程已經開始，蓋版視窗只會擋路。
- 關閉後不再自動彈出，重新載入頁面才會依上述條件再判斷一次。

**資料來源**

| 項目 | 內容 |
|------|------|
| API | `https://api.open-meteo.com/v1/forecast` |
| 金鑰 | **不需要**（回應帶 `access-control-allow-origin: *`，可跨站直接 `fetch()`） |
| 取樣點 | 24.6836, 121.7981（宜蘭五結，民宿所在、兩天行程重心） |
| 每日欄位 | `weather_code`、`temperature_2m_max`、`temperature_2m_min`、`precipitation_probability_max` |
| 逐時欄位 | `weather_code`、`temperature_2m`、`precipitation_probability` |
| 時區 | `Asia/Taipei` |

每日與逐時**在同一支請求內取回**，不多打一次 API。

**為何不用中央氣象署開放資料**：CWA API 需要申請金鑰，本站是公開靜態頁，金鑰無處可藏，因此改用免金鑰的 Open-Meteo。

**日期來源**：起訖日期由第 4.5 節的 `dayDates` 推導（`wxISO()` 負責把 0-based 月份 +1），**不另外寫死一份**，改行程日期時天氣與自動彈出期限會一起跟著變。

**上半部：兩天摘要（並排按鈕）**
- 兩張 **`<button class="wx-card">`** 並排（`.wx-grid` 固定兩欄，**手機也維持並排**，只縮小內距與字級），各顯示 emoji 圖示、中文天氣描述、高／低溫（四捨五入至整數）、最高降雨機率，底部一行「🕐 看逐時預報」。
- `WMO` 常數負責 weather code 對應圖示與中文；未知 code 退回 `🌡️` 與破折號，不會顯示 `undefined`。
- **摘要的天氣 code 由逐時自行推算（`wxDayCode()`），不直接用 `daily.weather_code`**：API 的每日值取「當日最嚴重」，一小時的極端值就會綁架整天的門面 —— 實測 2026-08-29 只有 17:00 是 code 96（雷雨夾冰雹）、全天雨量僅 6mm，卡片卻整天掛著冰雹，而宜蘭 8 月下冰雹實務上不會發生（數值模式對 96/99 的已知誤判）。改成只採「當日至少出現 2 小時」的 code，孤例不算數，取其中最嚴重者；全部落空才退回 API 的每日值。
- **降雨機率標「最高」二字**：`precipitation_probability_max` 是當日單一小時的最高值，不是整天下雨的機率。不標的話「100%」會被讀成整天都在下雨（實測 8/29 早上 09–12 時只有 11–59%、雨量 0mm，尖峰落在午後雷陣雨時段）。
- 選取狀態以 `aria-selected` 表示（珊瑚色外框 + 光暈），並帶 `role="tab"`／`role="tablist"`。
- 卡片下方顯示距出發天數，並標注「一週外的預報僅供參考，越接近出發越準」；出發當日起改為「預報會隨時間修正，出發前建議再看一次」。

**下半部：逐時預報表**
- 點任一天的按鈕，下方 `#tyHours` 列出該日逐時：時間 / 圖示 / 天氣描述 / 溫度 / 降雨機率（`.hr-row` 為 5 欄 grid，`.hr-list` 最高 44vh 可捲）。
- **選到的是今天時，已經過去的時段不列**（`isToday && hh < nowH` 直接跳過），標題改為「接下來的天氣」。行程進行中往回看幾點下過雨沒有意義，清單也不必再捲。未來的日子仍列滿 24 小時；**已經過去的日子維持完整列出**，切回去不會變成空白。
- **底色標記**：綠底 = 當天行程時段，紅底 = 現在這個小時（僅當該日就是今天）。
- 行程時段由 4.5 的 `startTimes` 推算（`wxTripHours()`：第一站開始時 ～ 最後一站開始時 +2 小時），**不另外寫死**，改行程時間時會自動跟著調整。
- 開啟時自動把清單捲到「現在」或「行程開始」那一列，不必自己找。
- 預設選取「今天」（`d.time.indexOf(wxTodayISO())`），出遊當天開頁就直接看到今天；不在行程兩天內則預設 DAY 1。

**時區處理**：所有「現在」的判斷都用 `Date.now() + 8 小時` 位移後以 UTC getter 讀出（`wxNowTW()`／`wxTodayISO()`），訪客不論在哪個時區結果都一致。

**降級**：抓不到（HTTP 錯誤、離線、回傳空陣列、`null`）時顯示「目前取不到天氣預報」訊息與重試提示，不留白。成功後於同一次瀏覽階段快取（`wxDone`），不重複請求；失敗則下次開啟會重試。

**互動與無障礙**：ESC／點遮罩／✕ 三種關閉方式；開啟時鎖背景捲動、焦點移至關閉鈕並做 Tab focus trap，關閉時焦點還給觸發元素；`aria-hidden` 同步切換。與 4.10 的住房指南視窗**共用同一組鍵盤處理**（`MASKS` 陣列查出目前開著的是哪一個）。

**約束例外**：本區塊是全站唯一的外部相依，破壞了第 2 節「無外部相依、可離線開啟」的原則 —— 即時資料本質上無法離線。影響侷限於此視窗；行程、地圖連結、費用試算、住房指南在離線時皆照常運作。

### 4.10 住房指南（分頁 ＋ 蓋版視窗）

民宿設備操作說明，行中查閱用。內容不隨時間變動，**完全離線可用**。

**進入方式**：第三個分頁「住房指南」（見 4.1）。分頁內為說明卡片與三顆按鈕：

| 按鈕 | `data-g` | 內容重點 |
|------|-----------|----------|
| 🚪 大門電子鎖使用教學 | `door` | 入住期間已解除密碼鎖可自由進出；睡前由室內轉鈕手動上鎖；全員外出時摸面板上鎖，返回輸入密碼後**務必按 `＊`** |
| 🔑 房間門鎖使用教學 | `room` | 碰面板喚醒 → 輸入房間密碼 → 按 `✓` 開門；密碼錯 3 次鎖定 5 分鐘 |
| 📺 大廳電視使用教學 | `tv` | 小支遙控器方向鍵＋`OK`、`圓圈`鍵回主畫面；YouTube 退房前登出、Netflix 免費；各房看各房頻道；輸入源 `HDMI 3` = 卡拉 OK、`HDMI 2` = 大廳 Switch |

**影片教學**：每則教學的 `video` 欄位放一支 YouTube Shorts 網址，視窗最上方會渲染一顆小型膠囊按鈕「▶️ 看影片教學」（`.gd-vid`，`target="_blank" rel="noopener"` 另開分頁）。**文字步驟不因此省略** —— 影片是補充，離線或不想看影片的人照樣看得到完整步驟。沒填 `video` 就不會出現按鈕。

**內容來源**：`GUIDE` 常數（`{ key: { title, video, html } }`）。`html` 為空字串時自動顯示 `GD_SOON`（「🛠️ 這項教學稍後補上」），**不會出現空白視窗** —— 新增第四則教學只要往 `GUIDE` 加一組、並在分頁裡加一顆帶對應 `data-g` 的按鈕即可。

**版面**：每則教學以 `.gd-sec` 分段（編號圓點 ＋ 標題 ＋ `<dl>` 名詞／說明對，必要時可加 `<p>` 前言與 `.gd-note` 附註），重點以 `<em>` 標珊瑚色，鍵盤按鍵以 `.gd-key` 標成按鍵樣式（例：`＊`、`✓`、`OK`、`HDMI 3`）。

**視窗**：與 4.9 共用 `.ty-mask`／`.ty-box` 樣式與鍵盤處理，但為獨立的 `#gdMask`，標題與內容於開啟時依 `data-g` 動態寫入，並把捲動位置重設到頂端。

| 項目 | 設定 |
|------|------|

| Repo / 分支 | `chenhsuping/yilan-trip` / `main`，來源路徑 `/`（根目錄） |

## 7. 維護指南

1. **改行程／費用**：編輯 `index.html` 中的 `trip` 資料陣列與費用試算常數（`sleep`、`bbq`、`mianshui`、`forest`）。
2. **改行程時間判斷**：同步更新 `dayDates` 與 `startTimes`。
3. **換分享縮圖**：替換 `og-image.png`（維持 1200×630）。
4. **重新部署**：`git commit` 後 `git push` 到 `main`，網址不變，約 1 分鐘生效。
5. **改／加住房指南內容**：編輯 `GUIDE` 常數的 HTML 字串（用 `.gd-sec` 分段）；新增一則就多加一組 `GUIDE` 項目與一顆對應 `data-g` 的按鈕，留空會自動顯示「稍後補上」。
6. **改行程日期時**：天氣預報的起訖日與自動彈出期限（`WX_AUTO_END`）都自動跟隨 `dayDates`，不需另外修改；但取樣座標 `WX_LAT`／`WX_LON` 若換縣市需一併更新。
7. **改自動彈出的截止時間**：`WX_AUTO_END` 的第 4、5 個參數是 UTC 時、分，台灣時間要減 8 小時（目前 `1,30` = 台灣 09:30）。
8. **注意**：GitHub 會自行對 `CNAME` 做遠端 commit；push 前若被拒，先 `git fetch` + `git rebase` 再推。
