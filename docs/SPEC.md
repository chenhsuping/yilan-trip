## 1. 產品概述

將一份宜蘭 2 天 1 夜的親子行程，從單張圖片升級為「會動、可互動、隨時間更新」的網頁。
目標使用者為參加此趟旅行的家庭成員（10 位大人、5 位兒童），用途為：行前瀏覽、行中導航、費用分攤查詢、以及分享給群組。

**設計語彙**：宜蘭在地元素（溫泉、三星蔥、雞）＋親子可愛風；暖色系配色、圓角、漸層、輕動畫。

## 4. 功能規格

### 4.1 天數切換（Tabs）
- DAY 1 / DAY 2 兩個分頁，點擊切換顯示對應行程。
- 切換時觸發煙火動畫（DAY 1 暖色、DAY 2 冷色）。
- 分頁列 sticky 固定於頂端。

### 4.2 時間軸（Timeline）
- 垂直時間軸，左側為序號圓點（依類型配色），右側為行程卡片。
- 卡片捲動進入視窗時淡入（IntersectionObserver，門檻 0.15）。

### 4.3 地圖導航
- 每個地點的地址為連結，點擊於新分頁開啟 Google Maps 搜尋。
- 連結格式：`https://www.google.com/maps/search/?api=1&query=<地點名稱+地址>`（URL 編碼）。

### 4.4 費用試算（Calculator）
含「大人 / 兒童」人數 stepper（預設 **大人 10、兒童 5**），即時計算：

| 項目 | 公式 | 是否隨人數變動 |
|------|------|----------------|
| 白色城堡包棟 | 固定 43,200 | 否 |
| 代烤燒肉 | 固定 17,000 | 否 |
| 免睡殿 | （大人＋兒童）× 150 | 是 |
| 萌萌森林 | 大人 × 250 ＋ 兒童 × 150 | 是 |
| **總計（不含餐飲）** | 上列四項加總 | — |

- **均分規則**：總額（含兒童門票）**只由大人均分**，兒童不分攤。
  `每位大人 = ceil(總額 ÷ 大人數)`（無條件進位，確保收足）。
- 餐飲（桶仔雞、莫內咖啡）與伴手禮（奕順軒）不列入試算，依現場為準。
- 免睡殿 6 歲以下、75 歲以上免費，如有免費者請自行下調兒童人數。
- 數字更新時有 count-up 與縮放動畫。

**範例（10 大 5 小）**：總計 NT$65,700，每位大人 NT$6,570。

### 4.5 依現在時間定位行程
- 以訪客**裝置本地時間**判斷目前進度。
- 行程時間表（供程式判斷，`[時,分]`）：
  - DAY 1（2026-08-29）：11:30 / 13:30 / 15:00 / 18:00
  - DAY 2（2026-08-30）：11:00 / 11:30 / 12:30 / 14:20
- 三種狀態：
  - **出發前**：標記第一站，徽章顯示「還有 N 天出發」。
  - **旅程中**：切到當天、捲動至當下站、卡片高亮＋「🔴 進行中」徽章。（此狀態才會自動捲動）
  - **結束後**（末站起 +3 小時）：標記末站「✅ 行程結束」。
- 右下「📍 目前行程」浮動按鈕：任何時候點擊都跳到當下該站。
- 每 60 秒自動更新徽章位置（不強制切頁／捲動，避免干擾閱讀）。

### 4.6 動畫清單
Hero 標題流光漸層、太陽脈動、雲朵飄移、emoji 浮動、溫泉蒸氣、載入煙火、時間軸圓點光環、卡片淡入＋hover 上浮與流光掃過、金額 count-up、進行中徽章閃爍、背景光點（canvas bokeh）。
蓋版視窗另有遮罩淡入與卡片彈入（見 4.9）。
**全部動畫遵守 `prefers-reduced-motion`，使用者關閉動態時停用。**

### 4.9 颱風路徑動畫（蓋版視窗）

行前掌握颱風動態用。內容為 NCDR「各國颱風路徑」動畫（多國預報路徑疊圖）。

**觸發方式**
- 右下浮動鈕 **🌀 颱風動態**（位於「📍 目前行程」上方），常駐可點。
- 首次造訪延遲 900ms 自動開啟一次，以 `localStorage` 鍵 `ty-seen` 記住，之後只走按鈕。
- 之所以不每次自動彈出：沒有颱風時該影片內容不確定，不該變成擋住行程表的空視窗。

**影片來源**

| 項目 | 內容 |
|------|------|
| 網址 | `https://watch.ncdr.nat.gov.tw/00_Wxmap/0A3_TYPHOON_MP4/{YYYYMM}/{YYYYMMDD}_{HH}.mp4` |
| 發布時段 | 每 6 小時，`HH` ∈ {02, 08, 14, 20}，**台灣時間（UTC+8）** |
| 規格 | 1382×720、約 36 秒 35 幀、H.264、約 1MB |

**如何取得「最新一支」（維護重點）**

NCDR 有清單 API（`wh/jn_typhoon_mp4`，回傳 JSON、最新排第一），**但它不送 CORS 標頭，跨站 `fetch()` 會被瀏覽器擋下**。因此改為純前端推算：

1. 以 `Date.now() + 8 小時` 位移後用 UTC getter 讀出台灣時間，取最近一個已發布時段（`HH < 02` 時退回前一日 `20`）。用 UTC getter 是為了讓訪客不論在哪個時區都得到相同結果。
2. 組出網址交給 `<video>`；若觸發 `error`（多為 404），**往前退 6 小時再試**，最多退 8 次（48 小時）。

回退不是防禦性冗餘 —— NCDR 產製明顯落後名目時段。實測 2026-08-23 台灣時間 14:0x 時 `20260823_14.mp4` 仍為 404，回退一格才命中 `20260823_08.mp4`。

**為何用 MP4 而非 GIF**：同名的 `.gif` 與 `.png` 也存在，但 GIF 為 8.7MB、MP4 僅 1.0MB，差 8.5 倍。

**播放行為**：`muted` + `loop` + `controls` + `playsinline` 自動循環播放（`muted` 需同時設 property 與 attribute，Safari 才允許自動播）。影片**非 faststart**（`moov` 在 `mdat` 之後），必須完整緩衝才會開始播，故需明確的載入中狀態。破快取查詢字串以 10 分鐘為一區間，避免每次開啟重抓 1MB。關閉視窗時 `pause()` 並清除 `src`，停止背景下載。

**三層降級**

| 層 | 觸發條件 | 顯示內容 |
|----|----------|----------|
| 1 | 正常 | 路徑動畫影片 ＋ 資料時間字幕 |
| 2 | 8 個時段全數失敗 | 靜態路徑圖 `00_Wxmap/images/track_map_{1s 深色｜2s 淺色}.png`（隨主題），並標註已降級 |
| 3 | 靜態圖也失敗 | 說明文字 ＋ 連往 NCDR 的連結 |

**互動與無障礙**：ESC／點遮罩／✕ 三種關閉方式；開啟時鎖背景捲動、焦點移至關閉鈕並做 Tab focus trap，關閉時焦點還給觸發元素；`aria-hidden` 同步切換。

**約束例外**：本區塊是全站唯一的外部相依，破壞了第 2 節「無外部相依、可離線開啟」的原則 —— 即時資料本質上無法離線。影響侷限於此視窗；行程、地圖連結、費用試算在離線時皆照常運作。

## 6. 部署規格

| 項目 | 設定 |
|------|------|
| 主機 | GitHub Pages |
| Repo / 分支 | `chenhsuping/yilan-trip` / `main`，來源路徑 `/`（根目錄） |
| 自訂網域 | `yilan.hsuping.org`（repo 內 `CNAME` 檔＋Pages 設定） |
| DNS | GCP Cloud DNS，`yilan` CNAME → `chenhsuping.github.io.`，TTL 5 分鐘 |
| HTTPS | 已強制（`https_enforced: true`），憑證由 GitHub 自動簽發 |

**為何用自訂子網域**：帳號的使用者網站 `chenhsuping.github.io` 綁定 `hsuping.org` 且為 SPA，會讓所有專案頁預設網址 301 轉走並被 catch-all 蓋掉；給本 repo 專屬子網域可繞過此問題。

## 7. 維護指南

1. **改行程／費用**：編輯 `index.html` 中的 `trip` 資料陣列與費用試算常數（`sleep`、`bbq`、`mianshui`、`forest`）。
2. **改行程時間判斷**：同步更新 `dayDates` 與 `startTimes`。
3. **換分享縮圖**：替換 `og-image.png`（維持 1200×630）。
4. **重新部署**：`git commit` 後 `git push` 到 `main`，網址不變，約 1 分鐘生效。
5. **颱風動畫壞掉時**：先確認 NCDR 是否改了網址規則 —— 開 <https://watch.ncdr.nat.gov.tw/watch_typhoon>，在動畫上按右鍵複製影片位址，比對 `TY_MP4` 常數與 `tySlotName()` 組出的檔名。時段若不再是 02/08/14/20，改 `tyLatestSlot()`／`tySlotBack()` 的 6 小時間距。
6. **不要改用 NCDR 的清單 API**：`wh/jn_typhoon_mp4` 雖然直接給出最新檔名，但它不送 CORS 標頭，從本站 `fetch()` 一定被瀏覽器擋掉。已驗證過，別重蹈覆轍。
7. **注意**：GitHub 會自行對 `CNAME` 做遠端 commit；push 前若被拒，先 `git fetch` + `git rebase` 再推。
